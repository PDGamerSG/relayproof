- feat: shadow traffic plugin. Mirrors a sample of live chat completions (streaming included) to candidate models off the request path, scores each pair with an optional LLM judge, embeddings and structural checks, and reports per-candidate readiness, latency and cost savings. Adds /api/shadow endpoints and canary routing-rule generation.
- feat: guarded ramp. `POST /api/shadow/promote` takes an optional `ramp` (`steps`, `min_requests`, `hold_seconds`); the canary guard then raises the canary's weight step by step while it stays healthy, writing each step into the same routing rule and logging `ramp` and `ramp_complete` events with the health each step rested on. Every step is judged on its own live traffic, an unhealthy step rolls back as before (or holds without `auto_rollback`), a later promotion replaces or cancels the ramp, and the ramp is persisted with the canary so a restart resumes it. Without `ramp`, behaviour and JSON are unchanged.
